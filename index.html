The Collection

THE COLLECTION

EVMs is a collection of 10,000 deterministic Ethereum wallet-style identities. Each piece is generated through a fixed Blockies-style algorithm using a deterministic seed — the same seed always produces the same identity. The visual system is built around the recognizable structure of Ethereum/EVM wallet identicons: grid-based cells, deterministic colors, and mirrored patterns.

Wallet Culture
Lore

Every wallet has an address.

Every address has an identity.

EVMs turns that invisible identity into something you can see.

An Ethereum address is a string most people recognize but never actually look at — forty characters, memorized only as a shape: the first few, the last few, everything else abstracted away.

EVMs takes that abstraction and makes it visible. Each identity is derived deterministically from its seed — nothing hand-designed, nothing arbitrary. The collection isn't about individual characters. It's about the identity behind the address.

FAQ

QUESTIONS

What is EVMs? +
EVMs is a collection of 10,000 deterministic Ethereum wallet-style identities built from the visual language of EVM address identicons.
How many NFTs are there? +
10,000, token IDs 0 through 9999.
What network is EVMs on? +
Ethereum.
What is the supply? +
Fixed at 10,000. No further minting beyond the original supply.
How are the identities generated? +
Each token's seed is derived from keccak256("EVMONHOOD" + tokenId), formatted as a 20-byte hex value. That seed drives a fixed Blockies-style algorithm: a deterministic PRNG fills an 8×8 grid, mirrors it horizontally, and derives three HSL colors from the same seed stream.
Are the identities deterministic? +
Yes. The same seed always produces the same grid, the same colors, and the same image — every time, by construction.
What is a Blockies-style identicon? +
The classic algorithm behind early Ethereum wallet avatars (used by MetaMask, MyEtherWallet, and others): a hash seeds a small pseudo-random generator that fills a mirrored grid and picks a small, fixed color palette.
How do I apply for GTD? +
Connect your wallet, then submit your X handle, wallet address, and a like/repost link in the GTD section above.
Which wallet should I use? +
Any injected Ethereum wallet (e.g. MetaMask) works. Use the wallet you intend to use for the mint.
Where can I view the collection? +
On OpenSea — see the link in the footer and the final section below.
What is the contract address? +
0x8e30458B36017Fad1D7381BF6CdC7bE8e4127674
Can I submit more than one wallet? +
Each wallet address may only submit one GTD application. Duplicate submissions from the same address are rejected.
